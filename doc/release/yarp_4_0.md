YARP <yarp-4.0.1> Release Notes
=============================


A (partial) list of bug fixed and issues resolved in this release can be found
[here](https://github.com/robotology/yarp/issues?q=label%3A%22Fixed+in%3A+YARP+yarp-4.0.1%22).

### libYARP_dev

* Some thrift messages have been renamed to follow the convention `nameData.thrift`.
  For example `MobileBaseVelocity.thrift` has been renamed to `MobileBaseVelocityData.thrift`.
* Fixed interface `IJoypadControl` and the corresponding devices. Removed method `getStickDoF()` (uncorrect
  because it sticks have only 2DOF) and added method `getAllAxes(std::vector<double>& values)`


### libYARP_os

* Removed deprecated class `PortablePair`, replaced by thrift.
  For example, `CommandMessage` data type is no more a `PortablePair`, it is now generated by `CommandMessageData.thrift`.
* yarp clean backend moved from libYARP_companion: added method `NetworkBase::cleanUnresponsivePorts(double timeout)`
  this fixed some dependency issues between different libs.
* Added flag RTLD_NODELETE to SharedLibrary::open() in NO ACE build, to prevent segfault on Ubuntu 26.04
* fixed data race condition in `PortCoreOutputUnit` (added mutex)

## CI

* Improvements to CI and Coverage tests

## Commands

### `yarpidl_thrift`

* Fixes issue preventing the correct generation of .thrift messages containing complex data type, e.g. list<list<double>> etc.
